# Flixie promotional video

Final: `flixie-promo-vertical.mp4`

23 seconds (22.8), 1080 × 1920, 30 fps, H.264 video and AAC stereo audio. Vertical format for social posts, Reels and Stories. Includes original instrumental audio and captions embedded in the picture; no voiceover.

The footage was captured from the running Flixie iPhone simulator: Search, film watch providers, and the watch-plan creation sheet. No invitation was sent. The capture contains the account’s existing friend handles in the plan picker.

The supplied `Documents/FLIXIE/text-logos/white.png` is used directly: “flix” white, “ie” purple. No AI redrawing of the logo.

Edit source: `build_promo.py`; recordings: `raw/`; title art and original score: `assets/`. The script uses Pillow, NumPy and FFmpeg. FFmpeg was installed into a temporary tools directory, so update its path if rebuilding on another machine.
