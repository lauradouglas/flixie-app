# Your first Flixie

Mobile interaction proposal, 29 September 2026. Mode: Operate. Extends Flixie's
existing purple, Manrope and mint visual language. Open index.html locally.

Use the journey buttons, or the screen selector beside/below the phone. Select
taste titles, save a recommendation, browse Anime, join explicitly and post a
sample reply. Preview the next visit to see a reply-led return state. Skip posting
to see a discovery-led alternative. Restart clears the in-memory demo.

The proposed incentive is accumulated personal usefulness and reciprocal social
activity. No streaks, invented urgency, reward currency or forced invitations.
Notification permission is offered only after participation; this preview records
no actual permission and sends nothing. Real invitation arrivals should bypass
unrelated setup and retain their destination.

This is a bounded concept, not a full authentication or recommendation implementation.
It uses three existing illustrative film posters. Service selection does not query
availability. Account entry, movie-night plans and navigation outside the journey
are explanatory prototypes. No user data is transmitted or persisted.

Before implementation: validate account requirements/build70 compatibility, private
taste signals, real shortlist diversity and availability, notification preferences,
privacy and spoiler handling. Test completion and meaningful first/return actions.

Validation: JavaScript syntax and local asset presence checked. Browser security
policy prevented rendering this local file; visual QA remains outstanding.
